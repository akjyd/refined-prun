# 中文翻译补丁工具

`specs/` 里每个文件是一组「原文 → 替换」规则和译文。运行 `python3 i18n-tools/run.py` 会：

1. 把规则涉及的文件恢复成官方版本（`main` 分支，可用环境变量 `I18N_BASE` 指定别的提交）；
2. 依次套用全部替换规则（每条原文必须恰好出现指定次数，否则报错）；
3. 重新生成 `src/i18n/en.ts` 和 `src/i18n/zh.ts`，再用 prettier 排版。

官方更新后：先把官方新代码合并到 `main`，再在 `zh-cn` 上合并 `main`，然后运行 `run.py`。
哪条规则报错，说明官方改了那段原文，按报错信息更新对应的规则即可。

新功能（一键关闭、飞船维修 ACT、HAUL、LOAN）是独立的新文件，不在规则里，直接改源文件。
